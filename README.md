# Churn_bank
Proyecto IUB: Predicción de Churn Bancario  - Dashboard interactivo para identificar clientes en riesgo de churn (abandono) y priorizar acciones de retención. 


- **Tecnologías:** Streamlit, Pandas, NumPy, Plotly, scikit-learn, python-pptx.

**Requisitos**
- Python 3.8+ (probado con Python 3.13)
- Recomendado crear un entorno virtual (venv)


**Archivos principales**
- `app.py`: Código principal de la app Streamlit.
- `requirements.txt`: Dependencias necesarias.
- `dataset_churn_banco_2.csv`: Dataset usado para el dashboard.
- `modelo_churn_pipeline.pkl`: Modelo entrenado (opcional, la app funciona en modo demo sin él).
